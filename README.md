# KakkiGPT


KakkiGPT is a chatbot application that utilizes OpenAI's GPT-3.5-turbo model to provide conversational AI capabilities. It is designed to be user-friendly and can be integrated into various plateforms for interactive communication.

# How to run BappyGPT

## 1. Clone the repository:
    git clone https://github.com/sanskarjain1503/KakkiGPT.git


## 2. Navigate to the project Directory:
    cd KakkiGPT


## 3. Create a virtual environment (optional but recommended):
    py -3.11 -m venv .venv


## 4. Activate the virtual environment:
    .venv\Scripts\activate


## 5. Install the required dependencies:
    pip install -r requirements.txt


## 6. Run the application:
    python app.py
